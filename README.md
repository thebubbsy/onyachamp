# OnyaChamp.com

Official website and software platform for **Matthew Bubb** (OnyaChamp).

Features:
- **MarkSmith Showcase**: Enterprise Markdown-to-Office & Document Compilation Engine.
- **Open-Source Tools**: `WingetIntune`, `WingetBatch`, `whisper-writer`, and PowerShell automation modules.
- **Architecture & Engineering Portfolio**: Pure ECMA-376 OpenXML, WinUI 3, Blazor WebAssembly, and Microsoft Graph cloud automation.

Hosted on GitHub Pages with continuous deployment via GitHub Actions.

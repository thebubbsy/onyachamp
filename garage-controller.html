broadlink-garage-controller

Smart Garage Door Controller for BroadLink RM4 Pro with dual architectures. Operates on Cloudflare Pages + Serverless D1 SQL database with a local Python / FastAPI LAN driver. Zero home servers left running 24/7.

4-Factor Crypto Auth
Device token, hardware fingerprint, dynamic nonce, and timestamp verification.
0ms Cold Start
Instant Cloudflare edge execution with Siri Shortcuts and CarPlay voice triggers.
  • Dual Runtimes: Serverless edge Cloudflare D1 stack + local LAN FastAPI Python daemon.
  • Mobile Keypad PWA: Snappy web keypad with biometric unlock, auto-rearm, and visual status.
  • Admin Device Whitelist: Manage authorized family devices, revoke access tokens, and inspect audits.
  • CarPlay & Siri Integration: Custom iOS shortcuts trigger the garage door hands-free while driving.

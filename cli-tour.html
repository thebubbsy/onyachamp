# Benchmark: Filtering 100,000 objects in memory (PowerShell 7.4)
PS C:\Engineering> Measure-Command { $items | Where-Object { $_.Name -like '*chrome*' -or $_.Name -like '*firefox*' } | Where-Object { $_.Name -notlike '*helper*' } }
TotalSeconds : 14.182471 (PowerShell Wildcard & Regex Engine)

# FindObject (fob) with SIMD-vectorized [String]::IndexOf & boolean parser
PS C:\Engineering> Measure-Command { $items | fob "chrome OR firefox NOT helper" }
TotalSeconds : 2.941829 (4.8x FASTER — zero scriptblock ceremony)
